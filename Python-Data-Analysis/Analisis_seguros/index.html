Hallazgos Estadísticos Clave

  • Vehículos antiguos mostraron mayor probabilidad de reclamación (t=6.41, p<0.0001)
  • Configuración de cilindros fue significativa (χ²=13.46, p=0.0002)
  • El número de airbags no mostró relación significativa (p=0.75)
  • Dataset desbalanceado (solo 6.4% de reclamaciones)

Técnicas Avanzadas Implementadas

Manejo de Outliers

Implementé un sistema robusto para identificar y manejar valores atípicos:

def handle_outliers(df, columns):
  for col in columns:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    df = df[~((df[col] < (Q1-1.5*IQR)) | (df[col] > (Q3+1.5*IQR)))]
  return df

Conclusiones y Recomendaciones

Insights Clave para la Empresa

  • Los vehículos con más de 5 años de antigüedad tienen un riesgo significativamente mayor de reclamación
  • La configuración del motor (cilindros) es un factor predictivo importante
  • Se recomienda ajustar las primas para vehículos antiguos
  • El dataset desbalanceado sugiere la necesidad de técnicas de muestreo especializadas para modelado predictivo
