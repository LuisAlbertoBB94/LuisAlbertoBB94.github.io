# Scrum Platform Analytics & Portfolio Management

A fully self-contained, serverless Agile Project Management and BI Dashboard platform built entirely with Vanilla JavaScript, HTML5, CSS3, and Chart.js.

## 🚀 Overview

This platform was developed as a robust, lightweight alternative to complex Jira/Azure DevOps setups, tailored specifically for Data & BI teams. It provides an executive-level overview of portfolio health, sprint tracking, and automated performance analytics—all running entirely in the client's browser.

**Key Features:**
- **Zero Backend Logic:** 100% serverless architecture. All state is maintained securely in the browser's `localStorage`.
- **Dynamic Configuration:** Full CRUD interface for adding Custom Business Areas, Team Members, and customizing the platform's visual branding.
- **Executive BI Dashboards:** Automated velocity charts, timeline cumulative progress, and real-time sprint burn-down analytics calculated directly from your tasks.
- **Presentation Mode:** A built-in slide deck view to instantly present project statuses to C-level stakeholders without ever opening PowerPoint.

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, CSS3 (Premium Glassmorphism Design)
- **Logic:** ECMAScript 6 (Vanilla JavaScript)
- **Data Visualization:** Chart.js
- **Persistence:** LocalStorage Engine
