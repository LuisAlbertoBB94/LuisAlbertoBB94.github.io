03. Lógica de Transformación

Validación de paridad financiera y limpieza de datos (Data Washing) utilizando Apache Spark sobre Google Cloud Storage.

Archivo: transform_logic.sh


#!/bin/bash
# Limpieza y Transformación Staging -> Model
staging_bucket=$1
model_bucket=$2

# Sometimiento de Job Spark
spark-submit \
    --master yarn \
    --deploy-mode client \
    --conf spark.sql.broadcastTimeout=2000 \
    --jars jars/spark-bigquery-with-dependencies.jar \
    src/staging_to_model.py
