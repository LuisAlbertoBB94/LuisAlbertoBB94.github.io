04. El Director de Orquesta: Apache Airflow

Ciclo de vida inteligente de datos desde la creación hasta la autodestrucción.

Coordinando el Flujo Elástico

Un pipeline de datos es tan fuerte como su eslabón más débil. Para evitar fallos silenciosos, utilizamos **Apache Airflow (Cloud Composer)** para orquestar cada micro-paso, desde la provisión del hardware hasta el refresco de las vistas de BigQuery.

Gestión de Errores y Retries

Implementamos una política de **reintentos exponenciales** (Exponential Backoff) para mitigar micro-cortes en la conexión con SAP, garantizando que el pipeline se recupere solo ante eventualidades de red.

El DAG (Directed Acyclic Graph)

Este es el flujo lógico que Airflow ejecuta cada hora para mantener el pulso del negocio actualizado.


# Definición del flujo lógico
# --------------------------------------------------

with DAG('pipeline_retail_realtime', schedule_interval='@hourly', ...) as dag:
    
    start = DummyOperator(task_id='inicio_proceso')
    
    infra = CreateDataprocClusterOperator(task_id='levantar_cluster_transiente')
    
    extract = BashOperator(task_id='ejecutar_extraccion_sap')
    
    transform = BashOperator(task_id='limpieza_y_paridad')
    
    cleanup = DeleteDataprocClusterOperator(task_id='eliminar_cluster_finops')
    
    # Dependencias: El cluster solo vive lo necesario
    start >> infra >> extract >> transform >> cleanup

Confiabilidad Operativa

Logramos una disponibilidad del pipeline del **99.9%**, permitiendo que los equipos de tienda confíen ciegamente en sus inventarios digitales reflejados en tiempo real.
