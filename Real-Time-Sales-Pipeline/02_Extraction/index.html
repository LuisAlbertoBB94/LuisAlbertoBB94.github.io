02. Lógica de Extracción (SAP HANA)

Script de Spark encargado de la conexión JDBC y la ingesta incremental de datos desde SAP HANA hacia el Landing Zone.

Archivo: extract_logic.sh


#!/bin/bash
# Extracción Incremental Spark - SAP HANA
landing_bucket=$1
staging_bucket=$2

# Sometimiento de Job a Dataproc
spark-submit \
    --master yarn \
    --deploy-mode client \
    --conf spark.scheduler.mode=FAIR \
    --jars jars/spark-bigquery-with-dependencies.jar,jars/ngdbc.jar \
    src/main_extractor.py
