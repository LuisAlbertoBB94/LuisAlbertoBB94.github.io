05. Capa Semántica (BigQuery)

Modelado de datos en BigQuery optimizado para Looker Studio, incluyendo el cálculo de márgenes brutos y métricas operativas al vuelo.

Archivo: materialized_view.sql


-- Materialización para Capa de BI
CREATE OR REPLACE VIEW `project.semantic_layer.vw_sales_performance` AS
SELECT
    store_id,
    transaction_date,
    net_sales_amt,
    quantity_sold,
    unit_cost,
    (net_sales_amt - unit_cost) AS gross_margin,
    CURRENT_TIMESTAMP() AS processed_at
FROM
    `project.model_layer.fact_ticket_detail`
WHERE
    status_code = 'SUCCESS';
